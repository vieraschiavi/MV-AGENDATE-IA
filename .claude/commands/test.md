---
description: Correr la suite de tests y reportar
---

Corré la suite del proyecto con **`npm test`** (equivale a `node --test`, corre
todos los `test/*.test.js`). Para un archivo puntual: `node --test test/<archivo>.test.js`.

Si fallan:
1. Mostrá el output del fallo.
2. Diagnosticá la causa raíz.
3. Proponé (o aplicá, si se pide) el fix mínimo.

Alcance opcional: $ARGUMENTS
